# chaozboiz-assets

Bilder für die Discord-Nachrichten des CHAOZ-BOIZ-Servers (SCP: Secret Laboratory). Nur PNG-Dateien, jeder Ordner ist eine Version und wird nicht mehr geändert: Ändert sich ein Bild, kommt ein neuer Ordner (`v2`), weil Discord Bilder unter derselben Adresse nicht neu lädt.

- `v1/profilbild.png`: Profilbild des Webhooks
- `v1/kopf-*.png`: Kopfbilder der Nachrichten (1200 × 300)
- `v1/klein-*.png`: kleine Bilder oben rechts (256 × 256)

## Changelog (`changelog/`)

Bilder für die Changelog-Nachrichten. Gleiche Regel: Jeder Ordner ist eine Version, geändert wird nichts, ein geändertes Bild kommt in `changelog/v2`. Ein neues Bild (zum Beispiel das Icon eines neuen Plugins) darf in den aktuellen Ordner.

- `changelog/v1/kopf/avatar.png`: Profilbild des Webhooks und Autor-Symbol (256 × 256)
- `changelog/v1/banner/*.png`: Rubrik-Banner (1000 × 200): neu, verbessert, behoben, neustart, wichtig, neutral
- `changelog/v1/icons/<plugin>.png`: ein Symbol pro Plugin (256 × 256), `_standard.png` als Rückfall

Basis-Adresse: `https://raw.githubusercontent.com/StanleyDE/chaozboiz-assets/main/changelog/v1`
