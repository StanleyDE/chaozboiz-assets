# chaozboiz-assets

Bilder für die Discord-Nachrichten des CHAOZ-BOIZ-Servers (SCP: Secret Laboratory). Nur PNG-Dateien, jeder Ordner ist eine Version und wird nicht mehr geändert: Ändert sich ein Bild, kommt ein neuer Ordner (`v2`), weil Discord Bilder unter derselben Adresse nicht neu lädt.

- `v1/profilbild.png`: Profilbild des Webhooks
- `v1/kopf-*.png`: Kopfbilder der Nachrichten (1200 × 300)
- `v1/klein-*.png`: kleine Bilder oben rechts (256 × 256)
